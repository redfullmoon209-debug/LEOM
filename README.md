# LEOM — Unity 3D RPG test project

LEOM is the new Unity project, independent of the legacy Godot repository. The new repository hosts only Unity scripts, test game data, build tooling and temporary geometry.

- Source project root: this repository root (Assets/, Packages/, ProjectSettings/)
- Unity Cloud project: https://cloud.unity.com/organizations/18968508051495/projects/8ff585f7-c6f7-4736-a844-1db884381c30
- Build target: WebGL (Unity 6000.3.0f1)
- Temporary character and map are procedurally generated in the Unity Editor.
- Multiplayer networking not yet implemented, and WebGL build not yet verified.

The original Leoonline Godot code and assets remain in their separate source repository, untouched.
